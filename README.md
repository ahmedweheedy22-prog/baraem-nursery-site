# موقع حضانة براعم — GitHub Pages + Supabase

الموقع العام يعمل كصفحة ثابتة على GitHub Pages. Supabase يوفّر قاعدة البيانات وتسجيل دخول لوحة الإدارة.

## الملفات

- `index.html` الصفحة العامة ونموذج استفسار ولي الأمر.
- `admin.html` لوحة الإدارة لتعديل النصوص وروابط الصور ومراجعة الاستفسارات.
- `style.css` and `admin.css` تنسيقات الموقع واللوحة.
- `config.js` بيانات الاتصال العامة بمشروع Supabase (رابط المشروع والمفتاح المنشور فقط).
- `main.js` تحميل محتوى الموقع وحفظ الاستفسارات.
- `admin.js` تسجيل دخول الإدارة وتحرير المحتوى.
- `schema.sql` إنشاء الجداول وسياسات الوصول والبيانات الأولية، مع مخزن صور عام.

## تجهيز Supabase

1. أنشئ مشروعًا جديدًا في Supabase.
2. افتح **SQL Editor**، والصق محتوى `schema.sql` وشغّله مرة واحدة.
3. من **Authentication → Users** أنشئ مستخدم الإدارة. لا تفتح التسجيل العام للزوار.
4. من SQL Editor شغّل أمر إضافة المستخدم إلى `site_admins` الموجود في آخر ملف `schema.sql`، بعد استبدال `ADMIN_EMAIL_HERE` ببريد الإدارة. كلمة المرور لا تدخل في SQL.
5. من إعدادات المشروع انسخ **Project URL** و**Publishable key** (أو المفتاح العام `anon` القديم)، ثم ضعهما في `config.js` مكان القيم التجريبية.
6. لا تضع **service_role/secret key** في ملفات الموقع أو GitHub. المفتاح المنشور مخصص للواجهة العامة، وسياسات RLS في SQL تحدد ما يستطيع الزوار والإدارة فعله.

## النشر مجانًا على GitHub Pages

1. أنشئ مستودع GitHub عامًا وارفع كل ملفات هذا المجلد إلى جذره؛ يجب أن يكون `index.html` في المستوى الأول.
2. افتح **Settings → Pages**، واختر **Deploy from a branch**، ثم `main` و`/(root)`، واضغط **Save**.
3. بعد انتهاء النشر، افتح الرابط الذي يظهر في صفحة Pages. رابط المشروع عادةً `https://USERNAME.github.io/REPOSITORY/`، ولو أنشأت مستودعًا باسم `USERNAME.github.io` يصبح الرابط `https://USERNAME.github.io/`.
4. لوحة الإدارة تكون على نفس الرابط مضافًا إليه `admin.html`.

## الاستخدام

- الزائر يرسل اسمه ورقم هاتفه ورسالة عامة؛ تظهر الرسالة في لوحة الإدارة.
- لا تجمع بيانات حساسة عن الأطفال مثل الحالة الصحية أو تفاصيل الحماية.
- استبدل بيانات الاتصال التجريبية والصور، واحذف رأي ولي الأمر التجريبي قبل النشر أو استبدله برأي حقيقي بموافقة صاحبه.
- حرّر المحتوى من `admin.html` بعد تسجيل الدخول. ارفع الصور من حقول الصور؛ تُحفظ في مخزن Supabase العام. استخدم صورًا مصرحًا بنشرها فقط.

## حدود الخطة المجانية

GitHub Pages يعطي عنوانًا فرعيًا مجانيًا على `github.io`؛ الدومين الخاص مثل `.com` يحتاج شراء. خطة Supabase المجانية محدودة وقد توقف المشروع بعد فترة من عدم النشاط، لذلك تناسب البداية والتجربة أكثر من موقع حضانة يعتمد عليه تجاريًا طوال الوقت.
